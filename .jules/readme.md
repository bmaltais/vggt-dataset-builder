# Readme Journal

## 2025-05-14 - [Initial Scan] **Learning:** The project uses a custom Meta VGGT License located in a submodule (`vggt/LICENSE.txt`). Standard license badges (like MIT/Apache) are not applicable; a custom badge or link is preferred. **Action:** Added a custom license badge linking to the submodule's license file.

## 2026-02-17 - [Quick Start Critical for Complex Tools] **Learning:** Projects with extensive setup requirements (uv environment, CUDA, HuggingFace auth, submodules) desperately need a Quick Start section. Visitors were jumping straight from "Key Features" to "Development" → "Setup" without a fast-track path to their first result. **Action:** Added Quick Start section (after features, before TOC) showing the 2-minute happy path: minimal install → auth → first run. Includes output location and next-steps links. Pattern: For CLI tools with >5 setup steps, always provide a condensed "copy-paste to success" path early in the README.
